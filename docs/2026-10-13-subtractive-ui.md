# 公开评测界面减法重构

公开页面收敛为评测结果、案例审阅和评测方法；运行评测与数据维护位于独立的管理入口。

## 页面职责与路由

| 页面 | 路由 | 默认阅读任务 |
| --- | --- | --- |
| 评测结果 | conclusions（默认） | 共同样本模型比较、评分观察、进入案例 |
| 案例审阅 | review | 同一任务的模型回答、维度分和原始评分理由 |
| 评测方法 | case_study | 专业任务范围、评分流程、数据边界与研究局限 |
| 运行评测 | test_run | 配置、运行/恢复、进入结果 |
| 数据维护 | samples | 专业样本 CRUD、评分导入导出、历史快照与独立裁判自测 |

结果页不再重复完整案例、方法正文和维护表单；筛选、维度比较、运行配置按需展开。案例选择只有一组原生选择器，具体样本、模型、批次随 URL 保存；旧 case_study / conclusions / samples / test_run URL 保持可访问。

案例页面复用既有评分详情和完整记录弹窗，去掉任务、回答、评分三个嵌套卡片的边框。专业标准严格读取运行时保存材料，历史缺失时保留提示，不以当前题库替代。原始引文验证、数值核查、原始响应和失败尝试均保留。各模型的最低分真实反馈仍保留，不因缺失标签而宣称没有问题。

运行队列、恢复配置、模型调用、评分逻辑、正式数据过滤和共同样本比较分母没有改动。结果表仅调整显示名称、列宽与数值格式；服务配置身份仍独立保留。运行失败与未完成记录仍显示，详细配置按需展开。
