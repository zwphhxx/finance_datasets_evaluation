# 公开阅读与评测路径调整

首页两个独立入口改为所有公开页面持续可见的三个主导航：**评测结果、评测流程、样本库**。当前页以蓝色文字和下划线标明；管理员原有导航和受控操作保持不变。

## 页面用途

- 评测结果：默认入口，选择已正式评分的案例与模型，查看历史回答、AI评分、原始反馈；“查看完整案例”进入下一级。
- 评测流程：配置评测 → 历史运行 → 查看结果。公开可交互浏览，真实调用仍禁用。
- 样本库：查看当前任务和评价标准、预览新增样本；正式保存仍禁用。
- 案例详情：属于进入它的结果页或流程页，返回文字明确指出父页。方法说明保留在结果页底部与源码文档。

首页改为明确的“评测结果”标题，移除两个重复入口；流程页、样本库移除重复的“返回作品首页”，共用主导航。未增加业务模块或图表。

## 阅读状态与证据

`navigation.py`仅按页保存case/run/model/score及stage/history查询参数。结果页与流程页各自保存选择；从案例通过主导航或返回按钮回到父页保留对应记录。无效记录仍明确报错，不用其他评分代替。

没有修改历史读取、评分口径、恢复队列、原始证据、管理授权或付费调用逻辑。当前题库与历史材料分别标注，历史证据缺失提示完整保留。
