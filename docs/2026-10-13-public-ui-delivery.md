# FinDueEval 公开展示版交付记录

日期：2026-10-13。保留三页架构、现有蓝灰配色与原始业务逻辑；没有新增图表、商业推荐或模型能力宣传。

## 改造与元素精简

| 原有元素 | 处理方式 | 原因与功能影响 |
| --- | --- | --- |
| 面向所有访客的管理菜单及接口配置 | 公开模式隐藏，并在服务端拦截操作 | 公开默认只读；管理员在本地或独立受控部署继续使用原有功能 |
| 样本维护、评测/恢复、裁判自测、快照上传、导入、请求日志管理 | 移入管理模式；直接页面调用也拒绝 | 不删除业务能力，访客无法通过 URL 或前端状态启用 |
| 结果页重复的运行数量和明细表 | 合并到“运行状态与测试条件”折叠区 | 真实失败保留摘要与详细原因，默认阅读更短 |
| 结果页统计及比较表 | 保留三个随筛选变化的指标和共同任务比较 | 模型/服务配置身份及共同有效任务口径不变 |
| 单个模型低分记录的反馈 | 保留原文短摘录与精确案例入口 | 不推广为模型整体表现；缺失反馈仍提示 |
| 案例回答与评分 | 保留桌面 60/40、移动单列评价优先 | 不删除回答；普通摘要至多三项，已记录的重要错误不受三项截断 |
| 维度、全部要点、评分理由、标准与技术记录 | 默认折叠 | 原始证据和历史标准仍可追溯；缺失时不替换为当前题库 |
| 方法页背景指标、重复解释 | 收敛为三个章节和一行流程 | 样本数动态计算；局限与源码入口保留 |
| 小屏长统计标签 | 调整标签最小高度 | 数值顶端对齐，不隐藏溢出，不裁切标签 |
| 未使用的样式作用域 | 清理 | 沿用 CSS 变量，不换主题 |

## 文案修改

| 原表述 | 修改后 | 原因 |
| --- | --- | --- |
| 财务/法律/投行场景大模型对比评测 | 专业场景大模型评测 | 简短、明确场景 |
| 案例审阅 | 案例分析 | 统一公开阅读目的 |
| 比较模型 / 配置 | 本次比较对象 | 包含独立服务配置 |
| 共同有效任务 | 可比任务 | 保持口径，降低默认技术密度 |
| 有效评分记录 | 有效AI评分记录 | 明确自动评分来源 |
| 低分案例反馈 | 低分案例与评价依据 | 明确单题反馈性质 |
| 评分摘要 | 评价结果 | 与回答形成清楚的阅读层次 |
| 全部评价点 | 全部检查要点 | 更自然的阅读用语 |
| 专业参考标准 · 运行时记录 | 参考答案与评价标准 | 仍只使用历史保存版本 |
| 运行与评分记录信息 | 技术与溯源信息 | 内部标识按需查看 |
| 详细技术信息与原始评分响应 | 原始技术记录 | 保留完整原始响应，压缩标题 |

首页使用用户指定标题和副标题；不声称自动评分是专家结论，字符串引文匹配也不写成专业充分验证。

## 实际修改文件

- `app/access.py`：单一服务端只读策略。仅进程环境 `FINDUEVAL_MODE=admin` 开启管理，公开为默认；查询参数、session_state 均不能授权。
- `app.py`：公开不初始化数据库；更新页面标题。
- `app/persistence/__init__.py`、`result_store.py`：公开不迁移结构；模式区分缓存；SQLite 使用原生只读 URI，缺失数据库不会创建。PostgreSQL 每个事务执行 `SET TRANSACTION READ ONLY`；只设连接参数在实际事务池中不足以保证当前事务只读。
- `app/db/init_db.py`、`repository.py`：阻止初始化及 CRUD 写入，公开原生连接只读。
- `app/models/siliconflow.py`：公开拒绝生成、联网模型列表及连接测试。
- `app/services/dataset_service.py`、`eval_runner.py`、`evaluation_workflow.py`、`judge_selftest.py`、`request_audit.py`、`sample_repository.py`、`scorer.py`：在写入、真实调用、启动/恢复等入口添加同一保护，不修改业务计算、权重或队列状态机。
- `src/ui/navigation.py`、`page_config.py`：三页公开导航和案例分析命名；管理仅受控环境开放。
- `src/ui/conclusions.py`、`history_view.py`：精简结果文案、统计标题、比较列和运行详情；复用原有精确跳转、共同任务和失败证据。
- `src/ui/review.py`、`trust_details.py`：案例阅读层次、详情命名、重大错误优先；历史不可用时准确说明当前任务查看范围。
- `src/ui/case_study.py`：方法页三个章节、动态样本数、一行流程。
- `src/ui/management.py`、`samples.py`、`test_run.py`：页面入口独立检查管理权限。
- `src/ui/report_styles.py`、`responsive.py`：清理未使用作用域，修复小屏统计对齐。
- `README.md`、`.env.example`：公开/管理部署边界、真实历史与仓库快照区别，未增加复杂认证系统。
- `tests/test_public_access.py`、`test_public_presentation.py`：新增公开越权、无费用/写入、空状态、故障、文案、统计及证据回归。
- `tests/conftest.py`：原有离线管理业务测试显式使用管理环境，公开测试移除此设置。
- 现有 UI 断言与方法文案夹具按新标题更新：`test_core_evaluation_flow.py`、`test_final_review_ux.py`、`test_navigation_routes.py`、`test_overview_findings.py`、`test_project_brief.py`、`test_project_brief_presentation.py`、`test_project_methodology.py`、`test_public_history_ui.py`、`test_report_experience.py`、`test_result_store_config.py`、`test_subtractive_ui.py`、`test_ui_text_guardrails.py`、`test_workbench_ui.py`、`fixtures/project_method_copy.txt`。评分业务标准未降低。
- 本交付记录与 `2026-10-13-public-ui-plan.md`：实施决定、验证范围与剩余事项。
