## 管理权限风险

当前管理页没有独立认证/权限校验；只检查配置和按按钮执行不构成访客授权。
如果公开部署已设置可用 API 密钥，访问管理页可能运行付费操作或修改数据。隐藏入口无效。
按本次范围约束记录风险，不引入认证后台、不发起任何真实调用或数据维护操作。
