# 无登录限额评测入口

用户已选择网站密钥及调用限额，明确不使用管理员登录。

目标：在评测流程页提供真实运行入口，多选正式样本和允许模型，按样本×模型计算任务数量，复用现有生成、自动评分、检查点及恢复流程。

默认硬上限：每天（UTC）10个任务，每任务最多5次对话请求（包括现有重试）；回答4096、裁判3072输出token上限。额度在数据库事务中原子预占，失败不退还。服务器可下调限额或关闭入口。请求量限制不等于固定金额。

架构：新额度账本及任务能力凭证只归属于新建公开任务。服务端 ContextVar 仅授予必要工作流/单题生成评分/对应运行表写入。管理权限仍为 false，题库维护、导入、原始历史恢复不会获得权限。密钥不进入表单、URL或日志。网页读取不创建表、不请求模型。首次明确开始操作才初始化新增额度表并预占。
