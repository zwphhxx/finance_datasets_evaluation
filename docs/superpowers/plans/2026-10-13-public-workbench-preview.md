# 公开可交互评测与样本预览

用户在极简版上线后明确要求恢复评测过程与新增样本界面，选择“公开可交互预览，调用与保存受控”。本计划替代“公开只看一个案例”的展示范围，不改变付费调用和持久化边界。

1. 首页保留简洁定位与代表案例，增加评测体验和样本库两个功能入口；预览页面均有返回首页入口。
2. 评测体验：配置模型/当前样本/生成参数，复用任务计划计算；真实调用按钮禁用。历史运行阶段显示真实批次状态，结果阶段显示对应记录及精确案例链接。历史记录与当前配置明确分开，不假装执行新任务。
3. 样本库：按场景筛选、选择任务、阅读当前标准；新增样本表单复用字段和标准构建器，仅会话预览，保存按钮禁用。草稿不加入正式题库或历史评分。
4. 只新增独立公开预览路由，不开放samples/test_run管理路由，不改app/access.py或核心评测服务。
5. 先写隔离AppTest覆盖配置计数、历史选择/精确跳转、草稿预览、缺失/空状态、权限和零副作用。再实现并跑完整pytest/Ruff/数据校验及原始指纹。
6. 实际截图1440/768/390/320，核对两个新入口与配置→历史状态→评分→证据路径。保留200%与真实iPhone的实测限制。完成后提交、push、确认CI和实际上线。
