# 公开作品首页与案例详情实施计划

**目标：**遵循用户给定结构，公开只留一个作品首页与案例详情；保留现有管理业务、原始记录及精确链接。

**架构：**新增一个公开阅读模块，复用现有正式记录筛选、历史任务恢复、回答关联、引文核对和专业标准阅读器。公开路由复用conclusions/review，旧case_study归首页方法位置；原有三页内容仅在受控管理模式保留。无需新框架、评分规则或数据格式。

**技术：**Streamlit原生组件、现有蓝灰CSS变量、pytest/AppTest、Ruff、浏览器截图。本会话按用户“直接完成”要求连续实施，不等待另一次设计审批，也不委派。

- [x] 确认当前HEAD/远端/CI；只读重查正式记录及历史材料缺失；15个原始文件和六表指纹保持不变。
