# 公开页面导航调整

目标：复用已有三个公开目的地，以持续可见的主导航取代首页两个孤立入口。评测结果为默认页，案例详情属于结果或流程的下级；不新增业务模块、评分指标或后台功能。

1. 在隔离的真实页面回归夹具中添加失败测试：三个入口持续可用、首页没有重复按钮、页面之间保留各自记录、案例详情回到正确父页、无效链接不被静默替换。
2. `navigation.py` 添加公开导航和按页保存的阅读状态；管理员原有导航保持原样。
3. `portfolio.py` 改为明确的评测结果标题与选择提示，删除两个重复入口，案例返回文案指向正确页面。
4. `public_preview.py` 删除重复的首页返回按钮，统一“评测流程”文案；配置、历史队列和评分逻辑保持原样。
5. 在既有公共样式与响应式层统一导航布局，测试1440、768、390、320px，以及结果→案例依据→返回、流程→样本库→返回和刷新。
6. 跑完整回归与Ruff，核对原始数据指纹，提交、push、检查CI与实际线上版本。

按页阅读状态仅保存查询参数；不包含凭据、历史回答或数据写入。公开默认路径不调用模型。截图保存在被忽略的本地验收目录。
