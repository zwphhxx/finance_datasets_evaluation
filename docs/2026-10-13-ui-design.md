# P0-UI 设计与实施记录

## 审查与范围

复用四个页面路由、原生导航、样本索引与维护弹窗、只读历史快照、正式评分读模型、持久化运行与恢复入口。原界面的暖色衬线大标题、过大的章节编号与分散的证据阅读路径不符合此次工作台定位。现有筛选及移动端重排能力保留。

## 设计

- 色彩：背景 #F8FAFC、白色内容 #FFFFFF、正文 #0F172A、强调 #2563EB、边框 #E2E8F0、次要文字 #64748B。
- 字体：标题与正文使用 PingFang SC / Microsoft YaHei 系统无衬线；数值使用等宽数字特性，技术原文保持原生代码组件。
- 布局：概览 → 发现与共同样本比较 → 任务与评分证据 → 方法与局限。评分详情采用任务/回答与评分/证据双栏，窄屏上下排列。
- 特色：专业任务、模型回答、要点检查、评分理由构成可直接核对的证据链；无实际结果时保留任务预览并明确空状态。
- 保持克制：不添加虚构结果、模型能力宣传、无依据图表或一级导航；默认浏览不调用模型。

## 实施顺序与验收

1. 概览及路由；2. 比较筛选、维度口径和双栏证据；3. 统一已有样式变量；4. 样本筛选与评测阶段；5. 1440 / 768 / 390 浏览器检查。

业务逻辑、样本原文件、原数据库与 API 安全机制不改动。新增测试覆盖真实统计、筛选共同分母、缺失及不匹配引文、双栏结构、空状态与默认路由。历史版本文案夹具保留，仅更新与新版视觉和导航明确冲突的旧 UI 断言。
