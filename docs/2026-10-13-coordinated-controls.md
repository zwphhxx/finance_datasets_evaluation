# 通用组件样式统一

本次沿用 Streamlit 原生组件和蓝灰视觉体系，统一常见组件的外观；未接入 Vue / Element Plus，也未新增前端构建或组件通信层。

## 修改

- `.streamlit/config.toml`：使用 Streamlit 1.51 支持的主题配置，统一白底输入区域、控件边框、6px 圆角和表格表头。
- `src/ui/components.py`：统一选择框、输入框、按钮、下载与提交操作、折叠区的尺寸和状态。多选标签采用浅蓝色，完整名称可换行。保留键盘焦点和禁用状态。
- `src/ui/responsive.py`：手机端流程选项保持等宽；320px 下按两字均衡换行。
- `tests/test_review_first_ui.py`：原禁用主按钮的样式断言改为覆盖所有禁用操作的共享规则；既有业务和权限测试继续保留。

修复了蓝色主按钮悬停时文字变深导致对比度下降，以及悬停样式覆盖输入焦点边框的问题。没有修改选择值、事件回调、路由、评分或权限判断。
