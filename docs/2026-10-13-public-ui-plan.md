# FinDueEval 公开展示版实施计划

目标：保留当前三页架构、蓝灰主题和真实评测口径，以只读公开展示及简短文案完成三分钟阅读路径。

用户已明确要求审查后直接实施，无逐项确认；本轮沿用已批准的页面结构。按设计审查、TDD与完成前验证流程在当前会话执行，不委派子代理。

## 现状与决定

- 精确案例链接、历史材料优先、共同有效任务比较、证据折叠和响应式布局已实现，直接复用。
- 当前管理导航对所有访客开放，结果库工厂自动补齐结构；必须先解决服务端只读边界。
- 公开模式为默认值；仅服务端 `FINDUEVAL_MODE=admin` 启用现有管理功能，要求在本地或有独立访问控制的部署使用。查询参数和session_state不参与权限判断。
- 公开模式不开SQLite种子初始化或结果库迁移，持久层连接只读；模型调用、评测启动/恢复、导入及资产写入均拦截。
- 首页保留三个筛选指标、比较表和短案例反馈；运行明细折叠，真实失败仍有摘要。
- 案例改称案例分析；沿用60/40与小屏评价优先，只重整文案和详情层级。仅整理已保存的下一步建议，不生成新的业务解释。
- 方法页收敛为样本设计、模型评测流程、方法局限三个章节，样本数量动态计算。
- 仓库无公开快照；已配置数据库有真实但不完整的历史记录。本轮不上传其原文或导出文件，README分别说明两种状态。
