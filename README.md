# 财务/法律/投行场景大模型对比评测

## 项目定位

本项目是面向财务、法律、投行专业任务的大模型评测原型。它不是通用 Chatbot，也不做脱离样本范围的泛化模型排名；核心是用脱敏专业样本、专业标准答案、评分标准、模型回答和 AI 评分，观察模型在当前样本范围内的回答质量、主要问题和使用边界。

项目不包含真实公司、真实交易或真实个人数据。当前结论只服务于样本内观察，不替代专业判断，也不构成模型整体能力或采购建议。

## 核心能力

- 脱敏专业任务样本库：维护任务题、业务背景、专业场景和测试状态。
- 专业标准答案与必须覆盖点：为 AI 评分提供稳定依据。
- 输入隔离：被测模型只看到任务题、业务背景和输出要求，不看到专业标准答案、必须覆盖点、不可接受错误或评分标准。
- 多模型回答对比：按样本和模型生成回答，保留成功、失败、重试和技术明细。
- AI 评分：保留五维权重，逐要点评价、匹配回答原文引文、核查固定算式并保存原始裁判响应；引文匹配不验证专业判断。
- AI 评测结论：成功 AI 评分直接形成样本内结论；跨模型质量只在兼容版本的共同有效任务上比较。
- 公开回放：完整快照只读加载，无 API Key 可查看真实历史；没有真实记录则明确显示空状态。
- 裁判自测及成本：手动9次裁判自测与正式结果隔离；全部请求尝试留痕，未知用量不记为0。

## 主流程

**案例展示 → 查看完整案例 → 查看完整评价依据 → 返回案例展示。** 公开导航另有“在线评测”和“样本与标准”。在线评测支持无需登录、使用网站密钥的限额真实评测，可多选样本和模型。先检查配置、存储、额度及免费模型目录，再点击“确认并开始评测”才生成回答和自动评分；中断任务需明确点击继续。配置、浏览与刷新不调用收费模型。

首页只展示项目定位、真实动态任务数量、一个当前任务设计和同任务的历史回答节选。当前题库与历史输入分别标注；历史材料缺失时明确提示。详情保持原始回答及评分，评价维度、检查要点、理由与当次参考标准集中展开，原始技术记录单独折叠。没有实测记录时仍可阅读任务设计及当前评价标准。

公开导航为案例展示、在线评测、样本与标准。详细比较、方法附录、数据维护及裁判自测保留在本地或独立受控管理环境。旧案例链接继续使用case/model/run/score精确定位。

## 当前样本集

当前版本保留 13 条脱敏专业任务样本：

- 财务场景：`FD-001` 至 `FD-005`，共 5 条；
- 法律场景：`LD-001` 至 `LD-004`，共 4 条；
- 投行场景：`CM-001` 至 `CM-004`，共 4 条。

样本来源为 `data/professional_samples_13.csv`。详细字段、数据结构和 SQLite / 文件映射见 `docs/dataset_schema.md`。

## 评测边界

- 样本为脱敏抽象任务，不包含真实公司、真实交易、真实个人或敏感数据。
- 被测模型不看到专业标准答案、必须覆盖点、不可接受错误或评分标准。
- AI 评分完成后直接形成评测结论。
- 结论基于当前样本、模型回答和 AI 评分生成；仅纳入正式评分，失败评分不进入评测结论。
- 结论只代表当前样本范围，不代表模型整体能力或采购建议。
- 实时模型调用依赖外部服务，不能保证每次都成功。

## 本地运行

建议使用 Python 3.11 或以上版本。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

如需使用自定义数据目录：

```bash
export FINDUEVAL_DATA_DIR=/path/to/data
streamlit run app.py
```

## 模型服务配置

可参考 `.env.example` 或 Streamlit Secrets 配置：

| 配置项 | 说明 |
| --- | --- |
| `FINDUEVAL_MODE` | 默认 `public` 只读浏览和限额评测；`admin` 仅用于独立受控管理环境，不是访客登录认证。 |
| `SILICONFLOW_API_KEY` | 硅基流动模型服务 API Key；不要提交真实 Key。 |
| `SILICONFLOW_TIMEOUT_SECONDS` | 回答阶段兼容原全局超时配置。 |
| `SILICONFLOW_ANSWER_TIMEOUT_SECONDS` | 回答阶段独立超时；未设置时沿用原服务配置。 |
| `SILICONFLOW_JUDGE_TIMEOUT_SECONDS` | 评分阶段独立超时，默认180秒，上限300秒；不继承回答阶段的90秒。 |
| `FINDUEVAL_EVAL_MAX_TOKENS` | 被测模型回答输出 token 上限。 |
| `FINDUEVAL_EVAL_TEMPERATURE` | 被测模型回答随机性；裁判评分固定为 `0.0`。 |

公开浏览保持只读，前端不能开启管理。真实评测须先预占额度：每日 UTC 全站最多10个“样本×模型”任务，每对最多5次对话请求（含自动评分、重试），每日全站最多50次请求；回答4096、裁判3072输出token上限，不等于固定金额。失败、刷新、重启不退还额度，只写本次新任务。恢复链接包含随机任务凭证，请勿分享；公开案例链接不包含凭证。
Secrets或环境变量中设置 `FINDUEVAL_PUBLIC_RUN_ENABLED=false` 关闭入口；`FINDUEVAL_PUBLIC_DAILY_TASKS` 下调每日额度（0关闭，上限10）。未配置真实模型密钥时运行前检查按钮保持禁用。存储未就绪时调用前拒绝；首次开始仅创建三个独立额度表，不修改历史表结构。
管理操作继续受控，本地可用 `FINDUEVAL_MODE=admin streamlit run app.py` 启用；独立管理部署需应用外访问控制。网站密钥不在页面、URL或记录中公开。

## 运行与恢复

点击“确认并开始评测”，系统会依次生成模型回答并自动评分。每条已完成的模型回答和评分都会增量保存到数据库；外部模型服务可能受网络、限流、模型响应时间和输出长度影响。评测中断后，由用户点击“继续本次评测”恢复剩余任务。

回答已成功保存但评分失败时，持有原恢复凭证的用户可在当次历史上下文、剩余请求额度和租约校验通过后，只重试AI评分。重试追加新批次并记录原回答身份与SHA-256，保留原失败记录；不重新生成回答，不重置原任务/样本模型对/每日额度。没有原材料或标准、已存在成功评分、凭证不匹配或预算不足时拒绝重评。新请求使用固定DeepSeek-V4-Pro及原五维规则，JSON协议与完整校验不变；本轮尚未授权新的收费联调，离线回归通过不代表真实评分已成功。

请求诊断升级需由受控迁移新增可空的 `request_attempts.diagnostics_json` 字段；公开浏览不执行迁移。新请求记录阶段超时、输入长度、HTTP状态与安全Trace ID，旧请求缺失信息保持空缺。

数据库不可用时，开始与继续评测会拒绝执行，不会调用模型服务。完整快照包含题目、回答、评分、状态、配置与请求尝试；只读加载不调用API、不写数据库。评分导出 / 导入只导入评分行；目标环境已存在相同运行批次、样本和模型的正式回答及批次记录才可纳入，并校验整数范围、总分与证据。

仓库没有提交真实运行快照，结果种子文件为空。已配置的历史结果库中有65条正式评分、覆盖13任务及5个模型/服务配置；另有39条mock裁判评分，按现有规则排除。正式历史缺少运行时任务正文、专业标准及结构化引文，不能称为完整证据，也不能用当前题库补造。公开部署可只读访问已有授权结果库；未配置或无法读取时显示空状态或不可用提示，仍能查看当前专业任务。当前没有 `public/evaluation_snapshot.json`；经来源、脱敏及公开范围核对后，才可放入已批准的快照。上传声明未经独立认证，自测答案和示例评分不是实测结果。

快照导出会排除实测批次内的模拟/裁判自测评分及对应队列和请求记录，保留正式失败与待运行记录，不改原数据库。导出与加载使用同一非正式记录规则。当前完整证据案例仍为0；本地候选通过格式与关联校验不等于获得公开批准。详见[最终验收记录](docs/2026-10-13-final-acceptance.md)和[待授权真实评测方案](docs/2026-10-13-evidence-run-proposal.md)。

裁判输出格式/服务错误最多重试2次；普通浏览和单元测试不产生模型API费用，独立裁判自测须点击标注费用的按钮。确定性公式当前仅覆盖原始 FD-001、FD-002、CM-001，材料变化时不应用旧公式。

本地 SQLite 数据库属于运行期产物，不应提交到 Git。

## Streamlit 部署

1. 将仓库推送到 GitHub。
2. 在 Streamlit Community Cloud 选择该仓库。
3. 设置主文件为 `app.py`。
4. 确认依赖来自 `requirements.txt`。
5. 公开部署不启用admin模式；仅浏览无需密钥。限额真实评测需配置网站密钥及可保存新运行与额度账本的持久数据库；管理部署仍须独立访问控制。
